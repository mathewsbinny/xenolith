# Middleware Converters

Engine-agnostic converters for third-party middleware commonly shipped in Xbox 360 titles.

## Current Middlewares
- `havok/` (`x360-havok`) — Havok Physics packfiles (4.6 / 5.5), data-driven endian conversion, MOPP trees
- `granny/` (`x360-granny`) — RAD Game Tools Granny 2 (`.gr2`) skeletons, animations, BE -> LE conversion, curves & CRC

Add new crates side by side here as needed (e.g. `physx/`, `morpheme/`, `facefx/`, `bink/`, `wwise/`, `scaleform/`).
